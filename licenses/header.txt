[English]

PDF R2L Script Win is a Windows GUI application with an installer that makes
PDF files right-to-left (R2L) with a two-column-right (spread) page layout.

It is a Rust reimplementation of "pdf-r2l-script" by INORIA
(https://github.com/INORIA/pdf-r2l-script), itself forked from "pdfr2l" by
hanepjiv (https://bitbucket.org/hanepjiv/pdfr2l). Both are licensed under the
MIT License, and so is this program. The source code is available at
https://github.com/aon-co-jp/pdf-r2l-script-win .
