[English]

PDF R2L RS is a GUI application (Windows / macOS / Linux / Android, with installers)
that changes the binding direction of PDF files (right-to-left "R2L" / left-to-right
"L2R"), can show them as a two-page spread, and can read scanned pages with OCR and
replace the text with searchable text in a matching typeface.

This program is an original implementation. Changing the binding direction is written
from the PDF specification (ISO 32000-1: 12.2 Viewer Preferences, 7.7.2 Document
Catalog) and does not contain source code from other "pdf-r2l" projects.
